🐙 KRAKEN NEURONS — live 3D activity viewer

Every neuron is one node of the running Kraken task graph (explore / general / verify / spec / conformance / fix / merge). Synapses are the node deps. Pulses travel along them when a node starts and when it completes. Colors follow the Kraken kind palette; flashes encode the kraken radio vocabulary (node_start node_end node_retry node_fix node_deferred node_rolled_back graph_converged…), plus K4.5 quality-escalation (violet ripple) and K4.6 model-swap (cyan shimmer).

1 · zero-click: watch the workspace live (recommended)

  • served over http — from the repo root npx serve . (or python -m http.server) then open http://127.0.0.1:3000/docs/viz/kraken-neurons.html: it tails .zelari/radio by itself at load — hot sessions seeded, new runs picked up automatically. No demo, no buttons.
  • opened as file:// — press 🔌 .zelari once and pick the repo root (or .zelari/radio): the folder is remembered (one permission click after a browser restart), every radio/workbench/plan log is tailed live, and runs started later appear automatically.
  • meanwhile, work: zelari-code --headless --kraken-graph "your goal" (or the TUI)

2 · tail one session only

  • press 📁 open log… and pick .zelari/radio/<sessionId>.jsonl — multi-select also workbench-<graphId>.md, .zelari/sessions/<sessionId>/events.jsonl, plan-<id>.json; dropping files works too. The handle is re-read every 500 ms, so it stays live.

3 · real-time push (companion SSE)

  • run zelari-code serve; the token is in ~/.zelari-code/companion.token
  • serve this page over http://127.0.0.1:… (loopback) — a file:// page cannot reach the companion because of CORS — then press 📡 sse

4 · demo

On first load a scripted kraken run plays (plan → explore → general → verify → rework/fix → merge, with one K4.5 escalation and one K4.6 model swap) using the real radio event schema. Press ▶ demo to stop it when real data arrives.

reading the organism

  • arms = topological waves: exploration ganglia near the core, writers and their verifiers down each tentacle, merge at the tip
  • a travelling pulse = node transition; red shockwave = error; yellow ring = retry; orange sprout = fix/rework spawn; violet ripple = quality escalation; golden wave = graph_converged
  • the weakness dot (Bennett) in the inspector: green = tightly asserted, red = loosely claimed
