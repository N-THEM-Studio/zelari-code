# Task t103: Harness: flattening di argomenti array nelle tool-call dirette (string[] → string)

- Status: **completed**
- Priority: high

FIXED in 0b9f9e4. Root cause: parseLooseArgs (packages/core/src/core/AgentHarness.ts) captured raw parameter text and truncated at ']' — JSON array/object values from direct tool calls arrived as display strings that downstream comma-splitting (coerceStringList) mangled into garbage globs. Fix: (1) dedicated well-formed <parameter name="k">full body</parameter> pass with coerceJsonishValue (JSON.parse; single-missing-bracket repair; legacy scalar unquoting fallback); (2) loose regexes now scan only text OUTSIDE parameter tags (no more garbage keys leaking from parameter bodies); (3) contract tests in agentHarnessToolArgs.test.ts (6/6 green): string[] native, object native, truncated-array repair, scalar legacy, no body-leak, bare <k>v</k> still works. Defense-in-depth: tool-side repair already shipped in 7b5c3d2 (coerceStringList). Unknown ≠ failed: the garbled key>value dump form retains its pre-existing (crude, greedy) behavior — documented in test expectations.
